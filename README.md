# 🚀 Maneger Of Reports do Portal Starcom Auto Portas

PortalStarcom é uma aplicação desenvolvida para atender às necessidades específicas de um usuário na **geração de relatórios**. Este projeto foi uma experiência extremamente enriquecedora, proporcionando um grande aprendizado sobre a usabilidade do **Firebase** e suas diversas funcionalidades.  

## 📌 Funcionalidades  

- 📑 **Geração de Relatórios**: Criação e organização de relatórios personalizados.  
- ☁️ **Integração com Firebase**: Utilização do Firestore para armazenamento de dados.  
- 🔐 **Autenticação Segura**: Login e gerenciamento de usuários com Firebase Authentication.  
- 📊 **Interface Intuitiva**: Dashboard simplificado para fácil navegação.  

## 🛠️ Tecnologias Utilizadas  

- **Frontend**: React.js  
- **Backend**: Firebase Functions  
- **Banco de Dados**: Firebase Firestore  
- **Autenticação**: Firebase Authentication
